# 综述撰稿 Skill

## 目标

生成可过结构校验、引用真实的 Markdown 文献综述。

## 章节要求

必须包含：**摘要 / 引言 / 研究现状 / 方法 / 挑战 / 总结 / 参考文献**

## 引用硬规则（代码强制）

- 只能使用检索得到的真实文献编号 `[1]..[N]`
- **禁止**列表外编号、禁止发明标题/作者/年份
- 末尾「参考文献」章节由系统用真实列表重编号重写
- 正文中无法映射到真实文献的 `[n]` 会被删除

## 文风

- 以 `# ` 标题开头，学术综述语气
- 禁止「已核实完毕 / 以下是报告 / 修正后重新输出」等过程说明
- 禁止整篇重贴、重复参考文献章节
- 长度建议 ≥800 字（目标 2500–5000）

## 主题模板（`templates.pick_report_template`）

| 主题线索 | 侧重 |
|----------|------|
| survey / 综述 | 方法谱系、对比表、研究空白 |
| change detection / 变化检测 | 任务定义、数据集指标、方法家族 |
| mamba / SSM | 与 CNN/Transformer 复杂度、扫描顺序 |
| CH4 / 大气 / 污染 | 观测平台、反演补全、物理+数据融合 |
| remote sensing / 遥感 | 模态、分辨率、基准、跨域 |
| rag / 检索增强 | 检索-重排-生成、评估、引用治理 |
| 其它 | 通用综述结构 |

## 质量门禁

结构分 / 引用覆盖 / 长度过低会触发**一次**结构化重写；仍不合格则保留清洗结果并记入 `quality_metrics`。
